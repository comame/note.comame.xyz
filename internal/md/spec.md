これはなに: Markdown とは微妙に互換性のないそれらしきもの

# 見出し1

## 見出し2
### 見出し3

## リスト

- リスト
  - リストアイテム
    - リストアイテム
- リストアイテム

- 空行を挟むと別のリストとして扱われる

- [ ] チェックボックス
- [x] チェックボックス

## 段落

通常の Markdown とは異なり、
行末の改行は無視されない。

空行をあけると別の段落として扱われる。

## コードブロック

```
Lorem ipsum
- コードブロック内では Markdown として解釈されない
```

## インライン要素

**太字** `インラインコード` [link](https://example.com) <https://example.com>

[l`i`**n**k](https://example.com) のように、組み合わせることもできる

## 拡張構文

:::details サマリ
内容は格納される
:::

:::details サマリ
::::details 内側のサマリ
::::
ネストできる
:::

; 定義リスト
: 説明はここに入る
; 定義2
: 説明2

## 非網羅的な既知の非互換

### 出力結果に違いが出る

- インライン要素は左からマッチする
    - 例: [outer?[inner?](https://example.com/inner)](https://example.com/outer)
- 文末の改行は無視されず、`<br>` タグが挿入される
- リスト間に空行を挟むと、別のリストとして認識される

### 制約

- リストの開始記号はハイフン (`-`) のみ
- リストのインデントは常に半角スペース2つ
- 画像はインラインに追加できない
